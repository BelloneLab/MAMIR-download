Download the installer for this computer, choose where to install MAMIR, and approve any operating-system permission prompt. The installer creates the isolated environment, installs the required packages, selects the fastest verified hardware path, and launches MAMIR.

Compatible NVIDIA hardware gets the verified CUDA route. Apple Silicon uses MPS. A verified Intel NPU gets its matching runtime. Every unsupported or failed accelerator safely uses CPU, without downloading CUDA packages.
